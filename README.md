# Helldivers Stratagems

Call down Helldivers-style stratagems in Minecraft. Enter an arrow-key code on the
**Stratagem Uplink**, throw the beacon, and watch the skies fall.

Targets **Minecraft Java 26.3** on **Fabric** and **NeoForge** from one shared codebase
(`common` + loader-specific `fabric` / `neoforge` modules).

## How to play

1. Get a **Stratagem Uplink** — craft it (iron, redstone and a compass), find it in the
   Tools & Utilities creative tab, or `/give @s stratagems:stratagem_uplink`.
2. Hold the uplink and press **G** to open code-entry mode.
3. Type the arrow-key code for the stratagem you want (HUD shows your input).
4. Press **G** again (or finish the code) to arm it, then **right-click** to throw the beacon.
5. Take cover. The effect lands after the stratagem's call-in delay.

## Building

Requirements: JDK 25, Gradle 9.x.

```sh
./gradlew build
```

This produces `stratagems-<version>-fabric-26.3.jar` and
`stratagems-<version>-neoforge-26.3.jar`. The Fabric jar needs
[Fabric API](https://modrinth.com/mod/fabric-api) for Minecraft 26.3.

Based on the MultiLoader template by Jaredlll08.
